# 🐾 任务宠物乐园（Task Pet Park）

> 完成每日备忘任务，养一只懂你的虚拟宠物。
> **任务与养成完全解耦** —— 喂养、玩耍永远不会变成任务；忘了喂食也不会影响任务进度。

一个零依赖的单文件 Web 应用：**纯前端 + localStorage 存档**，不需要服务器、不需要数据库、不需要构建。
手机、平板、电脑打开同一个网址即可使用（存档各自独立保存在本地浏览器里）。

**设计红线（代码里是硬约束）**

1. 喂食、送礼**不花金币、不影响任务进度** —— 任务只负责赚钱，养成只负责花钱。
2. 所有核心玩法免费开放；会员买到的是「省事」，不是「更强」或「更多」。

## 🚀 部署到 GitHub Pages（零安装，全程网页操作）

不需要安装 git，也不需要命令行。

1. 打开 <https://github.com/new>
   - **Repository name** 填 `task-pet-park`
   - 选 **Public**（GitHub Pages 免费版要求公开仓库）
   - 不要勾选 "Add a README file"
   - 点 **Create repository**
2. 在新建的空仓库页面点 **uploading an existing file**（或 Add file → Upload files）
3. 把这个文件夹里的 **`index.html`、`README.md`、`.nojekyll`** 三个文件一起拖进上传框
   （`.nojekyll` 是隐藏文件，Windows 里需要先在资源管理器「查看 → 显示 → 隐藏的项目」中打开才看得到；漏了它也能跑）
4. 下方 Commit changes 的输入框随便写一句，点 **Commit changes**
5. 进入仓库 **Settings → 左侧 Pages**
   - **Source** 选 `Deploy from a branch`
   - **Branch** 选 `main`，目录选 `/ (root)`，点 **Save**
6. 等 1–2 分钟，刷新这个页面，顶部会出现你的网址：

   ```
   https://<你的用户名>.github.io/task-pet-park/
   ```

这个网址就是**多端入口**：手机、平板、电脑浏览器直接打开即可，也可以「添加到主屏幕」当 App 用。

> ⚠️ 首次部署后如果 404，通常是三种原因：Pages 还在构建（等两分钟）、分支选成了别的、或者文件名不是 `index.html`。

## 💾 关于存档

- 所有数据（任务、金币、宠物、单调、会员演示状态）保存在浏览器 **localStorage**，关掉网页也不会丢。
- 换设备 / 换浏览器 = 一份全新的存档，**不会自动同步**（本项目没有后端）。
- 「我的 → 导出存档」会把整份存档 JSON 复制到剪贴板，可自行备份；「重置全部」清空重来。
- 「我的 → 模拟新的一天」可以手动触发跨天结算（饱腹/精力衰减、每日次数重置、连胜续接判断）。

## 🧪 本地测试

直接双击 `index.html` 就能用；也可以起一个本地静态服务（手机同一 Wi-Fi 下就能访问）：

```bash
# 任选其一
python -m http.server 8080
npx serve .
```

然后手机浏览器访问 `http://<电脑局域网IP>:8080/`。

## 🛠️ 技术说明

- 单个 `index.html`，约 100 KB，内联全部 CSS / JS，无框架、无构建步骤
- 宠物与搭配饰全部用 **CSS 手绘 + emoji**，不依赖任何图片素材
- 字体走 Google Fonts（Noto Sans SC），加载失败会自动回退到系统字体，布局不受影响
- 情感分析是基于中文关键词加权 + 语气符号的本地规则引擎（无网络请求，隐私友好）
